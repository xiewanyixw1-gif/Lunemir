# Lunemir

> A world that remembers you.

Lunemir 是一个本地优先、可高度美化的 AI 角色互动空间。项目目标是兼容常见角色卡、世界书与提示词预设，并通过悬浮小手机把角色的消息、剧情备忘和记忆延伸到聊天窗口之外。

当前版本已经从视觉原型进入可用的本地运行时阶段：角色、对话和配置写入 IndexedDB，可导入标准角色卡，并能直接连接用户自己的 OpenAI-compatible 接口进行流式对话。

## 本地运行

需要 Node.js 22 与 pnpm。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

静态产物输出到 `out/`，可由 Netlify 或 Cloudflare Pages 从 GitHub 自动构建。

## 项目原则

- 用户内容与 API 密钥默认只保存在当前设备。
- 导入内容始终先预览，不静默覆盖现有数据。
- AI 只能通过受约束的结构化事件修改长期记忆和手机状态。
- 基础体验必须能在不启用动画和模糊效果时正常使用。
